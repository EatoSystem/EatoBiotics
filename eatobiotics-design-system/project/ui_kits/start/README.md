# Start Landing Page Kit — `/start`, `/start-family`, `/start-mind`

High-conversion social-traffic landing pattern. One layout, three themed routes.

## Files
- `index.html` — toggles between all 3 route configs
- `Components.jsx` — `PathwayBadge`, `PrimaryCTA`, `InlineTextCTA`, `ScoreMock`, `StartHero`, `StartProblem`, `StartSolution`, `StartPressure`, `StartFinal`

## Route differentiation

| | `/start` | `/start-family` | `/start-mind` |
|---|---|---|---|
| Accent | `#4CB648` green | `#F5C518` yellow | `#2DAA6E` teal |
| Score | 68 | 62 | 59 |
| Lowest pillar | Rhythm (48) | Together (44) | Serotonin Foods (48) |
| Ring gradient | lime→green→teal | lime→green→yellow→orange | teal→green→lime |
| Audience | Individual | Parents/caregivers | Brain-fog, mood, focus |

## Section order
Hero → Problem → Solution → Pressure (dark) → Final CTA. Each section ends with an inline text CTA; the primary gradient pill recurs at Hero / Pressure / Final.
