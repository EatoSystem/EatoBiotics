# EatoBiotics Web UI Kit

High-fidelity recreation of the EatoBiotics marketing site (home + assessment flow).

## Files
- `index.html` — mounts the interactive demo with 3 view states (home / assessment / result)
- `Components.jsx` — `Header`, `Hero`, `SectionDivider`, `BioticTrio`, `Pathways`, `Manifesto`, `Tiers`, `Footer`
- `Assessment.jsx` — `AssessmentIntro`, `AssessmentQuestion`, `AssessmentResult` (animated score ring)

## Patterns
- Signature 5-stop brand gradient (Lime→Green→Teal→Yellow→Orange) used on primary CTAs, score rings, section dividers, and the single gradient clause in headlines.
- Dark-ground (`#1A2E12`) manifesto section sandwiched between light sections.
- Rounded-24 cards with a 6px top gradient bar and a muted photographic hero image.
- Fraunces serif for display + headings; Geist for body.
