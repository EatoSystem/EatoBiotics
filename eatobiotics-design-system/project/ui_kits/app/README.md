# EatoBiotics App UI Kit

Mobile-first iOS recreation of the Biotics Score app — home dashboard, log-a-meal flow, and meal-score results.

## Files
- `index.html` — mounts the phone frame with 3 navigable screens
- `Components.jsx` — `Phone` (device frame), `HomeScreen`, `LogMealScreen`, `ScoreScreen`, `TabBar`

## Patterns
- Animated `ScoreRing` with the 5-stop brand gradient as the stroke.
- Rounded-24 hero card on a soft-green (`#F7FAF5`) background.
- Primary CTA is always a full-width gradient pill.
- Pre/Pro/Post stats rendered in semantic colors (Lime / Teal-green / Orange).
